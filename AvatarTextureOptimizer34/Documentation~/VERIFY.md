# Unity 端验证清单 / Verification Checklist

> 本包代码在沙盒中无法运行 Unity，以下项目必须在真实 Unity 工程（Unity 2022.3 + NDMF 1.14.4 + VRC SDK 3.10.4）
> 中验证。按顺序执行；每项给出期望结果。发现问题请回传，团队据此修复。

## 0. 安装与编译
- [ ] 放入 `Packages/net.fosa.avatar-texture-optimizer/` 后无编译错误（含 asmdef 引用：ndmf、VRC.SDKBase、VRC.SDK3A、Burst、Collections、Mathematics）。
- [ ] 无 AAO 时编译正常（AAO 仅经反射访问）。
- [ ] 存在 AAO 1.9.17 时编译正常。

## 1. 组件与校验
- [ ] 在带 VRCAvatarDescriptor 的对象上添加组件成功；Inspector 折叠区正常，平台覆盖勾选后才显示。
- [ ] 挂载到无描述符对象 → 烘焙报错中止（error.mounting.descriptor）。
- [ ] 同一 Avatar 挂两个组件 → 烘焙报错中止（error.mounting.duplicate）。

## 2. 端到端烘焙（测试 Avatar：多网格、多材质、至少 2 张 1024+ 贴图、一个换装动画）
- [ ] 进度条显示各阶段；点取消 → 烘焙中止、无内存泄漏报错、临时资产保留。
- [ ] 控制台输出 `[ATO]` 报告（岛数、图集数、利用率、节省）。
- [ ] 烘焙后 Avatar 表现与优化前一致（目视 + 换装动画正常）。
- [ ] 组件在成品上被移除。
- [ ] 生成的图集资产名以 `ATO_` 开头；Read/Write 关闭、Wrap=Clamp、Mipmap⇔MipStreaming 同步。

## 3. 质量与缩放
- [ ] 近无损挡位：UV 不缩放、岛原样拷贝（图集内岛大小 = 原岛）。
- [ ] 高/中/低挡位：岛按目标质量缩小；低挡位明显更小；纯色岛缩到 min(4,短边)。
- [ ] 像素密度：大纹理小网格（低密度）不被过度缩小；小纹理大网格不被放大超过原尺寸。
- [ ] 透明（Blend）与 Cutout 贴图：边缘半透明/裁剪轮廓无可见劣化。
- [ ] 法线贴图：光照结果与优化前一致（角度误差阈值内）。
- [ ] 灰度/蒙版贴图（如 liltoon 的 Mask）：仅使用通道比较，无通道串扰。
- [ ] GPU 度量自检日志出现（diff<0.02 → GPU 启用；否则自动回退 CPU 并告警）。

## 4. 图集
- [ ] 多贴图合并为一个或多个图集；利用率报告合理（>60% 常见）。
- [ ] 同一 UV 组的 albedo 与 normal 图集：同一 UV 在两张图集上的位置一致（可用 debug 图对比）。
- [ ] 动画切换贴图：切换后贴图与基础贴图在同一 UV 位置（动画不跳变）。
- [ ] padding=4/8/16/32/64 生效；岛间无渗色到无法接受（已知允许轻微渗色）。
- [ ] 勾选 NPOT：图集为 64 步进尺寸；iOS 目标无 PVRTC 且控制台有 warning。
- [ ] 白名单贴图完全不动；与白名单同 UV 的贴图跳过图集化但整图缩放生效。
- [ ] wrap 越界网格（跨接缝）→ 该通道白名单 + warning，无 UV 改动。

## 5. 动画/引用
- [ ] 换装动画（m_Materials.Array.data[i] 切换）在优化后仍正确。
- [ ] 贴图属性动画（m_Materials.Array.data[i]._MainTex 对象引用曲线）指向新图集。
- [ ] ST 动画的贴图 → 白名单（警告），动画继续工作。
- [ ] 渲染模式/Cutoff 动画：按最严苛评估，优化后两种模式都不劣化。
- [ ] 形态键网格：烘焙后形态键权重动画表现一致（顶点拆分 + 形态键重建正确）。
- [ ] 动画缩放物体：按最大缩放评估，大缩放时不发糊。
- [ ] 材质槽合并后动画绑定索引正确（无跳槽）。

## 6. 兼容性
- [ ] 安装 AAO 并启用 Remove Mesh by Mask（使用 UV0）：优化后 AAO 仍使用原始 UV（疏散通道生效），遮罩结果与未优化时一致。
- [ ] liltoon 2.3.4 材质：主色/法线/Mask 均正确；MatCap/反射贴图自动跳过（warning）。
- [ ] 未安装 MA：插件直接可用（顺序约束仅在有 MA/AAO 时生效）。

## 7. 性能与内存
- [ ] 中等 Avatar（~20 张贴图）烘焙耗时合理（分钟级内）；无 RenderTexture/NativeArray 泄漏报错。
- [ ] 取消后内存回落（无泄漏）。

## 已知偏差（有意为之，见 README）
- CPU 回退评估分辨率上限 1024px；GPU 路径全分辨率。
- 多岛 GPU 批处理为逐岛 dispatch（性能优化项，未做批）。
- 采样空间近似：GPU blit 在贴图存储空间内处理预乘/法线，CPU 路径在严格线性空间。
