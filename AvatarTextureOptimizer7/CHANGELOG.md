# Changelog

## 0.1.0

- Initial development release of Avatar Texture Optimizer (ATO).
- NDMF pass after Modular Avatar / late-transform and before Avatar Optimizer.
- UV-island quality scaling (MS-SSIM + CIEDE2000 + alpha / normal / gray).
- Shape-based Burst bitmask atlas packing with type groups and UV groups.
- Platform overrides (PC / Android / iOS), i18n (en / zh-Hans), extension API.
