# 目标质量算法 — 指标、阈值与文献依据（Coder 共识 v1）

## 1. 总体流程

```
原贴图（导入后有效像素，线性空间）
   │  岛覆盖区（原生分辨率）
   ▼
候选缩放 s（每岛每槽，二分搜索）
   ▼ 线性重采样（透明=预乘 alpha；法线=解码→重采样→重归一化→编码）
缩小覆盖区
   ▼ 双线性上采样回原尺寸
重建覆盖区
   ▼ 与原图（岛掩码内）逐指标比较，全部达标才算通过
```

- 所有指标在线性空间计算（sRGB 贴图先转线性；sRGB<->线性转换 Burst 查表+LUT 插值加速）。
- 比较范围严格限定岛掩码内；岛外像素不参与。
- 透明贴图预乘 alpha 下采样与上采样（直通 alpha 会产生黑边伪影与错误的 MS-SSIM/ΔE）。
- 被多材质引用时：对每个引用材质的透明模式与 Cutoff 逐一评估，取最严苛。
- 贴图被不同材质以不同用途引用（如一个作主色一个作蒙版）：各用途指标都算，取最严。

## 2. 指标定义

### 2.1 结构相似度 MS-SSIM / SSIM

- 按 Wang, Simoncelli, Bovik, "Multi-scale structural similarity for image quality assessment"（IEEE Asilomar 2003）实现：5 级（原尺寸 → 每级 2 倍降采样），逐级比较亮度 l、对比度 c、结构 s，加权积（默认权重按原文：0.0448, 0.2856, 0.3001, 0.2363, 0.1333）。
- 岛包围盒短边 < 176px：退化为单尺度 SSIM（σ=1.5，窗口 11×11，Gaussian 权重）——小窗口多尺度不可靠。
- 岛包围盒短边 < 11px：跳过本指标（计为通过）——样本太少无统计意义。
- 不透明贴图：MS-SSIM + ΔE00 双指标。

### 2.2 色差 ΔE00（CIEDE2000）

- 按 Sharma, Wu, Dalal, "The CIEDE2000 color-difference formula"（Color Res. Appl. 30(1), 2005）实现：线性 RGB → XYZ(D65) → CIELAB → ΔE00。
- 指标取岛内像素 ΔE00 均值（也可扩展 p95，默认只用均值）。
- JND（just-noticeable difference）约为 ΔE=1；ΔE<1 通常不可感知（Mokrzycki & Tatol, "Color difference ΔE - A survey", 2011）。因此默认挡位均值阈值 1.0。

### 2.3 Alpha

- Cutout：按每个引用材质的 cutout 阈值 clip 出轮廓（α≥cutoff），比较重建图与原图的轮廓 IoU（Intersection over Union）。
- Blend：线性空间 alpha 逐像素 RMSE。
- 贴图被多个材质引用 → 逐材质评估取最严。
- 阈值依据：8bit alpha 量化步长 1/255≈0.0039；默认 RMSE 0.005（约 1.3/255）在感知上接近无损；cutout 轮廓 IoU 0.9995 对应边缘错位 <0.05%。

### 2.4 法线贴图

- 正确解码（Unity DXT5nm：xy←ag，z=√(1-x²-y²)）→ 线性重采样 → 重归一化 → 编码回存储格式。
- 比较解码后切线空间向量角度误差（degrees）：均值 + p95。
- 依据：3Dc/BC5 法线压缩研究表明亚度级误差通常不可感知（van Waveren, "Real-Time DXT Compression"; id Tech 5 相关研究）；默认均值 0.25°、p95 1.0° 远低于可感知阈值。

### 2.5 灰度贴图

- 仅在"被使用的通道"上比较（由着色器分析 + 像素兜底判定使用通道）。
- 线性空间 RMSE，逐通道取最差。
- 阈值同 alpha 量级（8bit 量化 JND 附近）。

## 3. 预设挡位（折叠于高级选项；挡位变化时参数值相应变化；自定义挡位不被其他挡位覆盖）

| 挡位 | MS-SSIM | ΔE00 均值 | Cutout IoU | Blend α RMSE | 法线 均值/p95 | 灰度 RMSE |
|---|---|---|---|---|---|---|
| 极高 | 0.9995 | 0.5 | 0.9999 | 0.002 | 0.15° / 0.5° | 0.002 |
| 高（默认） | 0.999 | 1.0 | 0.9995 | 0.005 | 0.25° / 1.0° | 0.005 |
| 中 | 0.997 | 2.0 | 0.998 | 0.01 | 0.5° / 2.0° | 0.01 |
| 低 | 0.995 | 3.0 | 0.995 | 0.02 | 1.0° / 4.0° | 0.02 |
| 自定义 | 全部 1（近无损） | — | — | — | — | — |

- 近无损（质量=1）：跳过对应贴图类型岛的 UV 缩放（含纯色岛），不重采样、原样拷贝。
- 纯色岛（质量<1）：直接缩到 min(4, 原包围盒短边)。
- 像素密度带：默认 [2048, 4096] px/m（挡位 512/1024/2048/4096/8192）。语义（已向用户说明的解读选择）：Dmin 硬下钳（防糊），Dmax 仅告警（质量优先）。

## 4. 性能设计

- 指标核函数（Bilinear 重采样、预乘、SSIM/MS-SSIM、ΔE00、角度误差、RMSE）全部 `[BurstCompile]`，`IJobParallelFor` 按岛/像素并行。
- 光栅化走 GPU（GPUMeshAPI，经 `AtoGpuUtility` 单点封装），指标评估用 CPU Burst（float32，避免 GPU 读回抖动）；大图集合成用 GPU RenderTexture blit 链。
- 缓存：岛光栅掩码（4px 粒度）、原贴图线性像素（每贴图一次解码）、缩小覆盖区（按 (槽, s) 惰性计算 + LRU）。
- 不包含最终压缩格式引入的损失（导入压缩后的误差由用户参数决定，不进质量评估）。

## 5. 与文献/业内的对照说明

- 阈值设计对齐业界"感知无损"实践：游戏纹理流式加载与 mip 生成普遍采用 SSIM 类门限 0.99+；ΔE JND=1 是色彩学公认界限；法线与灰度 RMSE 阈值取 8bit 量化 JND 量级并留裕量。
- 所有阈值可在高级选项内按挡位修改；挡位切换即切换参数组。
