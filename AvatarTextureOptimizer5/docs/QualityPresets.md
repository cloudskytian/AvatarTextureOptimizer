# ATO 目标质量挡位参数表（待用户审阅）

> 本表为 AgentTeam 依据学术与业内基准提出的默认值。经用户确认后写入 `QualityPreset.cs`，
> 并全部折叠在「高级选项」中供用户修改。

## 一、依据来源

| 指标 | 依据 |
|---|---|
| **MS-SSIM** | Wang, Simoncelli & Bovik (2003) *Multi-Scale Structural Similarity for Image Quality Assessment*。5 尺度、11×11 高斯窗（σ=1.5）。因此最小可评估边长 = 11 × 2⁴ = **176px**，与用户设定的回退阈值完全一致。 |
| **ΔE (CIEDE2000)** | Sharma, Wu & Dalal (2005)。业内共识：ΔE00 ≈ 1.0 为「恰可察觉差异」(JND)；≤2.0 为「仔细对比才能看出」；≤3.0 为「一般观察者不可察觉」；>5 明显可见。 |
| **法线角度误差** | 实时渲染惯例：法线偏差 1° 对高光位移的影响低于 8bit 量化噪声；3° 以内在 VRChat 常见的 Lambert/Toon 着色下不可辨。采用 p95（95 分位）而非均值，避免局部塌陷被平均掩盖。 |
| **灰度 RMSE** | 线性空间 RMSE，8bit 量化步长 = 1/255 ≈ 0.0039。阈值以量化步长的倍数表达。 |
| **像素密度** | VRChat 社区主流实践：面部 2048–4096 px/m，身体 1024–2048 px/m。取默认 min 2048 / max 4096（用户已指定）。 |

## 二、默认挡位（5 档 + 自定义）

数值含义：**该指标必须达到或优于此阈值，UV 岛才允许继续缩小**。二分搜索取所有指标中最严苛者。

| 参数 | ①最高质量 | ②高 | ③均衡(默认) | ④性能 | ⑤极限压缩 | 自定义 |
|---|---|---|---|---|---|---|
| **质量因子** `quality` | 1.00 | 0.95 | 0.85 | 0.70 | 0.50 | 1.00 |
| MS-SSIM 下限 | *跳过* | 0.995 | 0.985 | 0.970 | 0.945 | 1.0 |
| 单尺度 SSIM 下限<br><sub>(短边<176px 回退)</sub> | *跳过* | 0.990 | 0.975 | 0.955 | 0.925 | 1.0 |
| ΔE00 平均上限 | *跳过* | 0.8 | 1.5 | 2.5 | 4.0 | 0 |
| ΔE00 p95 上限 | *跳过* | 1.5 | 2.5 | 4.0 | 6.5 | 0 |
| 法线角度误差 p95 (°) | *跳过* | 0.75 | 1.5 | 3.0 | 5.0 | 0 |
| 灰度 RMSE 上限<br><sub>(线性, ×1/255)</sub> | *跳过* | 1.0 | 2.0 | 4.0 | 7.0 | 0 |
| Cutout 轮廓 IoU 下限 | *跳过* | 0.998 | 0.993 | 0.985 | 0.970 | 1.0 |
| Blend alpha 线性 RMSE<br><sub>(×1/255)</sub> | *跳过* | 1.0 | 2.0 | 3.5 | 6.0 | 0 |
| 最小像素密度 (px/m) | 4096 | 2048 | 2048 | 1024 | 512 | 2048 |
| 最大像素密度 (px/m) | 8192 | 4096 | 4096 | 2048 | 1024 | 4096 |

### 说明

1. **①最高质量 (quality = 1.0)**：按用户规格，**完全跳过 UV 缩放**（含纯色岛短路），
   不重采样、原样拷贝。仍参与图集化、去重、导入参数优化。
   因此该列所有感知指标标记为「跳过」——它们不会被计算，节省大量时间。

2. **自定义挡位**：默认全部为「近无损」(1.0 / 0)，用户自行修改后
   **不会被其他挡位切换覆盖**（独立存储字段）。

3. **切换挡位时**，上述所有参数值随之联动变化；用户手动改动某一项后，
   该项在 UI 中标记为「已覆盖」，切换挡位仍会重置（自定义挡位除外）。

4. **像素密度挡位**选项：512 / 1024 / 2048 / 4096 / 8192（用户已指定）。

5. **木桶效应**：同一 UV 组内不同贴图各自算出目标尺寸后，取**最大**者，
   且不超过该 UV 组内最大的原始尺寸。

6. **纯色短路**：quality ≠ 1 时，纯色岛直接缩到 `min(4, 原岛包围盒短边)`。
