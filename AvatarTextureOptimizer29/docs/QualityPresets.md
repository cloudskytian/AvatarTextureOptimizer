# 质量挡位依据 / Quality Presets Rationale

参数与默认挡位（Balanced）依据（学术/业界）：

| 参数 | Balanced | 依据 |
|---|---|---|
| MS-SSIM ≥ | 0.98 | Wang et al. 2003 (MS-SSIM)；业界图像编码评估常以 ≥0.98 为"高质量"，≥0.99 接近不可分辨 |
| ΔE00 mean ≤ | 1.5 | CIEDE2000 的 JND ≈ 1.0–2.3 (Sharma 2005)；1.5 为安全中间值 |
| ΔE00 p95 ≤ | 3.5 | 允许少量像素超 JND，p95 控制尾部 |
| 法线角度 mean ≤ | 1.5° | BC5/ASTC 法线压缩典型误差 ~1°(van Waveren & Castaño 2008) |
| 法线角度 p95 ≤ | 4° | 同上，尾部控制 |
| Cutout IoU ≥ | 0.995 | 剪影保持；自定义经验值 |
| Blend alpha RMSE ≤ | 3/255 | 线性空间 alpha；低于常见 8bit 抖动级别 |
| 灰度 RMSE ≤ | 2.5/255 | 逐使用通道最差；低于 DXT 量化噪声 |

挡位表（preset → 参数）：
- NearLossless(近无损，Custom 默认即此档，对应"全部为1"）: 0.999 / 0.5 / 1.5 / 0.5° / 2° / 0.999 / 1.5/255 / 1/255
- High: 0.99 / 1.0 / 2.5 / 1° / 3° / 0.998 / 2/255 / 1.5/255
- Balanced(默认): 0.98 / 1.5 / 3.5 / 1.5° / 4° / 0.995 / 3/255 / 2.5/255
- Fast: 0.96 / 2.5 / 5 / 2.5° / 6° / 0.99 / 5/255 / 4/255
- Custom: 用户改，编辑任一参数自动切 Custom，Custom 参数不被其他挡位覆盖。

密度钳制（像素密度 px/m，基于岛覆盖三角形的世界面积，含形态键/动画缩放因子）：
默认 min 2048 / max 4096；挡位 512/1024/2048/4096/8192。同时对原贴图真实像素尺寸做上限钳制（永不放大）。

规则：
- 目标质量==1（NearLossless 且 quality slider==1）：跳过 UV 缩放（含纯色岛），原样拷贝。
- 纯色岛（所有像素同色，容差 1/255）且目标质量<1：直接缩到 min(4, 包围盒短边)。
- MS-SSIM: 岛包围盒短边 <176px → 单尺度 SSM；<11px → 忽略该指标（统计无意义）。
- 全部指标取最差值判断（对同一贴图的多个引用材质的透明模式/cutoff 取最严苛）。
